KIDS DRESS PHOTOS

Put all Kids Dress product photos in this folder.

PHOTO SIZE RATIO
Use portrait 3:4 ratio, for example 1200 x 1600 px.
The showroom card is tall, so 3:4 fills it with no ugly cropping.
Keep each photo under 1 MB so the site loads fast.
Save as .jpg, simple name, no spaces, for example pink-party-kids-dress.jpg

HOW TO PUBLISH
Step 1. Open this folder on GitHub, click Add file, then Upload files.
Step 2. Drag your photo in and click Commit changes.
Step 3. In the Owner Portal image field type: products/kids-dress/YOUR-FILE-NAME.jpg
