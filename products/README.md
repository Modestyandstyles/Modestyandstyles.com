# Product Photos
Put all product photos in this folder.
How to add a photo:
1. Open this products folder on GitHub.
2. Click Add file, then Upload files.
3. Drag your photo in and click Commit changes.
4. Copy the link below and paste it into the Owner Portal image field:
https://modestyandstyles.com/products/YOUR-FILE-NAME.jpg
Tips:
- Use simple file names with no spaces, for example royal-diamond-abaya.jpg
- Keep each photo under 1 MB so the site loads fast.
- Portrait photos look best in the showroom grid.
